Helena

Uma camada em cima do Claude Code que chega zerada e aprende o seu jeito de trabalhar, carrega skill só quando precisa e só guarda o que o benchmark prova que ajuda. A layer on top of Claude Code that starts blank and learns how you work, loads skills only when they are needed and only keeps what the benchmark proves helps.

a sua helenayour helena

Ela chega zerada. Aprende com você.She arrives empty. She learns from you.

Quando você instala, ela não sabe nada sobre você: nenhuma memória, nenhum kit, nenhuma skill sua. Vem só o mecanismo: os hooks que sempre rodam, a memória que se grava sozinha e o benchmark que decide o que fica. Cada correção sua vira uma nota. Cada procedimento que se repete vira candidato a skill. Quanto mais você usa, melhor ela fica. When you install her, she knows nothing about you: no memories, no kits, none of your skills. Only the machinery ships: hooks that always run, memory that writes itself and a benchmark that decides what stays. Every correction you make becomes a note. Every procedure you repeat becomes a skill candidate. The more you use her, the better she gets.

por que existe · a helena do criadorwhy it exists · the creator's helena

Eu estava ensinando a mesma coisa toda semana.I kept teaching the same thing every week.

Li todas as minhas sessões com o Claude Code, em 15 projetos. O padrão era sempre o mesmo: eu corrigia, a IA acertava e, na sessão seguinte, esquecia. Eu tinha uns 60 skills instalados e quase nenhum era chamado na hora certa. Ter skill não basta. Ela precisa aparecer quando o pedido precisa dela, e sair quando não ajuda. I read every Claude Code session I had, across 15 projects. The pattern never changed: I corrected the AI, it got it right, and the next session it forgot. I had about 60 skills installed and almost none were called at the right time. Having a skill is not enough. It has to show up when the request needs it, and leave when it does not help.

  1. 01Cria skillsCreates skills

    Pedido repetido 20+ vezes, ou 5+ vezes em 2+ sessões, vai pro Haiku. Ele só escreve a skill se houver um procedimento de verdade. A skill entra na biblioteca, você é avisado com o comando pra apagar, e se ninguém usar por 30 dias ela sai.A request repeated 20+ times, or 5+ times across 2+ sessions, goes to Haiku. It only writes a skill if there is a real procedure. The skill goes to the library, you get a notice with the command to delete it, and if nobody uses it for 30 days it is removed.

    /helena:undo
  2. 02Desliga pluginsTurns off plugins

    Plugin que um projeto nunca usa é desligado só naquele projeto. Pediu algo que precisa dele ("vamos pôr um gateway de pagamento" → Stripe) e ela liga de novo; vale ao reiniciar a sessão. Plugin com hook nunca é desligado.A plugin a project never uses is switched off in that project only. Ask for something that needs it ("let's add a payment gateway" → Stripe) and she turns it back on; it applies when the session restarts. Plugins with hooks are never switched off.

    .claude/settings.local.json

a regrathe rule

Skill é sugestão.Hook é garantia.Skills suggest.Hooks enforce.

O que tem que acontecer sempre (não subir chave de API, não commitar na main, checar se o texto dá pra ler) vira hook e roda sem pedir. Skill fica pro que é conhecimento: a receita, o formato, o caminho. Whatever must always happen (no API keys in git, no commits to main, readable text) becomes a hook and runs without asking. Skills are for knowledge: the recipe, the format, the path.

para empresasfor teams

A Helena do seu time, montada pra ele.Your team's Helena, built for it.

De graça ela aprende uma pessoa. Num time, o ganho vem de todo mundo começar com as mesmas regras, os mesmos kits e a mesma memória do projeto, e de provar com número que valeu o investimento. For free she learns one person. In a team the gain comes from everyone starting with the same rules, the same kits and the same project memory, and from proving with numbers that it paid off.

01

Instalação no time. Todas as máquinas configuradas, memória compartilhada do projeto num cofre do time, status line e painel ligados.Team rollout. Every machine set up, shared project memory in a team vault, status line and panel on.

02

Regras da empresa em hook. Branch protegida, padrão de commit, arquivos que nunca sobem, segredos do seu stack. Hook cobra, ninguém precisa lembrar.Company rules as hooks. Protected branches, commit conventions, files that never go up, your stack's secrets. A hook enforces it, nobody has to remember.

03

Kits sob medida. As skills do seu stack, revisadas por segurança, entrando só quando o pedido precisa. Menos contexto, menos custo.Custom kits. Skills for your stack, security reviewed, loaded only when a request needs them. Less context, lower cost.

04

Benchmark com as suas tarefas. O trabalho real do time rodando com e sem a Helena. Fica só o que ganha, e você vê o placar.Benchmark on your tasks. Your team's real work run with and without Helena. Only what wins stays, and you see the scoreboard.

05

Relatório de tokens. Onde o time gasta contexto, o que dá pra cortar e quanto isso vale no fim do mês.Token report. Where the team spends context, what can be cut and what that is worth at the end of the month.

06

Treinamento. Uma sessão pro time usar Claude Code com a Helena: handoff, memória, sessões curtas.Training. One session for the team to use Claude Code with Helena: handoffs, memory, short sessions.
