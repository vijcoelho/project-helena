economia de tokenstoken savings

Cada mensagem relê o contexto inteiro.Every message re-reads the whole context.

A conta de uma sessão é o tamanho do contexto vezes o número de chamadas. Por isso a Helena ataca três coisas: o que entra no contexto, quantas chamadas acontecem e se o contexto é lido do cache ou pago inteiro.A session's bill is the context size times the number of calls. So Helena goes after three things: what enters the context, how many calls happen, and whether the context is read from the cache or paid in full.

Comando reescrito, não recusadoRewritten, not refused

Recusar um comando custa mais uma chamada ao modelo, e cada chamada relê tudo. Quando basta uma flag, a flag entra e o comando roda. Só flags são acrescentadas: o código de saída e o sentido do comando ficam iguais. Quando algo é cortado, a IA é avisada na mesma hora.Refusing a command costs one more model call, and every call re-reads everything. When a flag is enough, the flag goes in and the command runs. Only flags are added: the exit code and the meaning of the command stay the same. When something is cut, the AI is told right away.

Nada é mexido quando o comando já diz o que quer (-v, -n 5), quando a saída vai pra um arquivo ou pra outro comando, dentro de texto entre aspas, ou com # helena:full. Se o rtk estiver instalado, o rtk rewrite dele vai primeiro: conhece muito mais comandos que esta tabela.Nothing is touched when the command already says what it wants (-v, -n 5), when the output goes to a file or to another command, inside quoted text, or with # helena:full. If rtk is installed, its rtk rewrite goes first: it knows many more commands than this table.

Ainda barradoStill blocked

O que nenhuma flag deixa enxuto sem mudar o sentido: despejar um arquivo acima de 100 KB, um lockfile, saída de build, git log -p sem limite, listagem recursiva com node_modules. A recusa já diz o jeito enxuto.What no flag makes lean without changing its meaning: dumping a file over 100 KB, a lockfile, build output, an unbounded git log -p, a recursive listing with node_modules. The refusal names the lean way.

A barra de statusThe status line

subagentessubagents

Subagente na rédea.Subagents on a leash.

Um subagente criado sem modelo roda no modelo principal, e nasce com dezenas de milhares de tokens de contexto antes de fazer qualquer coisa. Sempre ligado: worker general-purpose sem modelo roda no Sonnet e o Explore no Haiku. Um pin nunca sobe o modelo: numa sessão Sonnet só o Explore muda, numa sessão Haiku nada muda. Tipo de agente com modelo próprio e chamada que nomeia um modelo ficam como estão.A subagent started without a model runs on the main one, and starts with tens of thousands of context tokens before it does anything. Always on: a general-purpose worker without a model runs on Sonnet and Explore on Haiku. A pin never moves a model up: on a Sonnet session only Explore changes, on a Haiku session nothing does. An agent type with its own model and a call that names one are left alone.

benchmark

Só fica o que ganha.Only what wins stays.

Cada tarefa roda como uma sessão inteira do Claude Code, uma vez sem a Helena e uma vez com. Cada rodada registra acerto, turnos, custo e os tokens em quatro partes (sem cache, escrita de cache, leitura de cache, saída). Com várias rodadas, as colunas se revezam em quem vai primeiro. Uma sessão barata que falha não é economia: o que conta é o custo por tarefa resolvida.Every task runs as a full Claude Code session, once without Helena and once with her. Each run records pass or fail, turns, cost and its tokens in four parts (uncached, cache write, cache read, output). With several rounds, the columns take turns going first. A cheap session that fails is not a saving: what counts is the cost per solved task.

python eval/run.py -n 1                          # todas as tarefas, 1 rodadaevery task, 1 round
python eval/run.py noisy-tests -n 3              # uma tarefa, 3 rodadasone task, 3 rounds
python eval/run.py --model opus                  # outro modeloanother model
python eval/run.py --probe                       # o peso fixo da Helena: um "Reply OK" por colunaHelena's fixed weight: one "Reply OK" per column
