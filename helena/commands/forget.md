1. The vault path is the single line in `~/.helena/vault` (if missing, use `~/Helena`). Notes live in `<vault>/Memory/`.
2. Find the notes that match (by name, `description:` or content). Show the user which ones and what they say.
3. If only part of a note is wrong, edit that part. If the whole note is wrong, delete the file.
   Ask before deleting when more than one note matches.
4. Reply in one line with what changed.
